## Project Description

This project is a simple health appointment booking system written in Java. It manages appointments with general practitioners, specialists, nurses, and dietitians.

## Features

- Display information about health professionals.
- Add appointments for patients.
- Check appointment times and prevent double bookings.
- Find appointments by professional ID or patient phone number.
- Sort appointments by time.
- Cancel appointments.
- Show messages when a booking or cancellation cannot be completed.

## How to Run

1. Open the project in IntelliJ IDEA.
2. Make sure a Java JDK is configured.
3. Open `src/AssignmentOne.java`.
4. Run the `main()` method.
5. Check the results in the console.

## Project Structure

Java source files are stored in the `src` folder. The project uses encapsulation, inheritance, polymorphism, and abstraction.
